# 🎬 SeriesHub

**SeriesHub** es una aplicación web desarrollada con React y Vite que permite descubrir, explorar y consultar información sobre series de televisión, así como guardar tus series favoritas.

## ✨ Características principales

- Catálogo de series de televisión.
- Buscador para encontrar series.
- Exploración de series por categorías.
- Fichas detalladas con información de cada serie.
- Consulta de temporadas y episodios.
- Sistema para añadir y eliminar favoritos.
- Persistencia de favoritos mediante LocalStorage.
- Navegación entre páginas mediante React Router.
- Diseño responsive adaptado a móviles, tablets y ordenadores.

## 🛠️ Tecnologías utilizadas

- React
- JavaScript
- Vite
- HTML5
- CSS3
- React Router
- API TVmaze
- LocalStorage

## 🚀 Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone https://github.com/andreapv1999/series-hub.git
```

### 2. Acceder a la carpeta

```bash
cd series-hub
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Iniciar el servidor de desarrollo

```bash
npm run dev
```

### 5. Generar la versión de producción

```bash
npm run build
```

## 🌐 API utilizada

El proyecto utiliza la API pública de [TVmaze](https://www.tvmaze.com/api) para obtener información sobre series, temporadas y episodios.
