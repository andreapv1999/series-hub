# 🎬 SeriesHub

Aplicación web desarrollada con React y Vite para descubrir, explorar y guardar series de televisión favoritas.

## ✨ Características

- Catálogo de series.
- Buscador de series.
- Exploración de series por categorías.
- Ficha detallada de cada serie.
- Información sobre temporadas y episodios.
- Sistema de favoritos.
- Diseño responsive adaptado a móviles, tablets y ordenadores.
- Navegación entre páginas.

## 🛠️ Tecnologías utilizadas

- React
- JavaScript
- Vite
- CSS
- React Router
- API TVmaze
- LocalStorage

## 🚀 Instalación

Clona el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

Entra en la carpeta del proyecto:

```bash
cd SERIES-HUB
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```

## 📦 Compilación

Para generar la versión de producción:

```bash
npm run build
```
